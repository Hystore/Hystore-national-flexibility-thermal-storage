# Contributing to HYSTORE

First of all, thank you for your interest in contributing to the HYSTORE Open Source Project! We welcome contributions from the community to help advance thermal energy storage management.

## 🛠 How Can I Contribute?

### Reporting Bugs
- Check the [Issues](https://github.com/Hystore/{REPOSITORY_NAME}/issues) page to see if the bug has already been reported.
- If not, open a new issue. Include a clear description, steps to reproduce the bug, and your environment details.

### Suggesting Enhancements
- Open an issue with the tag `enhancement`.
- Describe the feature and why it would be useful for the HYSTORE ecosystem.

### Pull Requests (PRs)
1. **Fork** the repository and create your branch from `main`.
2. **Issue first**: For major changes, please open an issue first to discuss your proposal.
3. **Coding Standards**: Follow the project's coding style (e.g., PEP 8 for Python).
4. **Documentation**: Ensure any new features or changes are properly documented.
